# Contributing

Thank you for helping. For now:

- **Bugs and ideas**: open an issue (the form asks for the version, browser and page type).
- **Code**: we are not merging outside pull requests yet. Describe the change in an issue instead; if we use it we
  credit you in the changelog.
- **Translations**: corrections to the French, Arabic or German text are very welcome as issues.

For a project on your own website (fixes, training, a version for your agency), write to hello@getayka.com.
